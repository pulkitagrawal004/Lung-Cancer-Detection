<h3 align="center">Lung Cancer Detection</h3>



Clone:
-------------------------------------------------------------------------------------------------
git clone https://github.com/theomhatwar/lung-cancer.git

Run backend:
-------------------------------------------------------------------------------------------------
cd backend

pip install -r requirements.txt

python app.py

Run frontend:
-------------------------------------------------------------------------------------------------
cd frontend

npm install

npm run dev

Run new-ui:
-------------------------------------------------------------------------------------------------
cd new-ui/my-app

npm install

npm run dev

Web Link
-------------------------------------------------------------------------------------------------
http://localhost:3000/
